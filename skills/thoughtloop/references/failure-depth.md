# Failure-depth routing

Fix the level that evidence says is wrong:

| Depth | Signal | Action |
|---|---|---|
| `IMPLEMENTATION` | Local bug or omission; strategy still fits | Minimal revision and regression checks |
| `STRATEGY` | Local fixes repeat or the approach conflicts with a criterion | Reconsider the approach |
| `ASSUMPTION_OR_FRAME` | A premise, constraint, or problem boundary was falsified | Challenge or rediscover |
| `EVIDENCE_GAP` | A needed test, source, or measurement is missing | Verify or run an experiment |
| `CONTRADICTION_OR_LIMIT` | Requirements, tools, permissions, or budget block a defensible result | Escalate or report the blocker |

Do not alternate between the same approaches without new evidence. Revisit rejected work only when a constraint, assumption, or observation materially changes.
