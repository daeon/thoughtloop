# Solution-space search reference

Optimize for meaningful coverage per token, not idea count. Search across the
lenses that fit the task: the simplest credible solution, removing or moving
work, changing a boundary, exploiting existing capability, changing state
ownership or timing, solving an upstream cause, inverting a constraint, or
using an adjacent-domain analogy.

Two options are not materially different when they keep the same architecture,
assumptions, and mechanism and only change libraries, wording, or minor details.

When a choice depends on an empirical unknown, define the smallest experiment
that distinguishes the competing hypotheses and states which result changes
the decision. Stop when relevant families are covered, ideas become variants,
one option dominates the important constraints, or evidence is more valuable
than more ideation.
