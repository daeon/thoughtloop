# Budget and delegation policy

ThoughtLoop owns delegation. Public nodes may identify a narrow opportunity,
but they do not spawn orchestrators or recursively delegate.

| Budget | Initial delegation | Follow-up |
|---|---:|---:|
| `light` | one narrow independent question | none |
| `balanced` | up to two complementary questions | one targeted round |
| `deep` | up to three complementary questions | one targeted round |

Use a fresh context when the host supports it. Each delegated result must name
the bounded question, evidence inspected, result, uncertainty, and whether it
made edits. The parent owns the contract, synthesis, edits, evidence, final
outcome, and user communication.

Use lower-cost agents for bounded inspection, search, or mechanical review when
adequate. Reserve stronger reasoning for disputed evidence, difficult tradeoffs,
and final synthesis. If delegation cannot add independent signal, do not use it.
